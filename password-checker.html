Entropy explained

A mathematical estimate of the search space

0 bits

This estimate uses the size of the character set detected and the password length. In a simple model: entropy = length × log₂(character-set size).

It assumes each character was selected randomly from that character set. Human-created passwords usually do not meet that assumption, so entropy should not be treated as a complete measure of real-world password security.
